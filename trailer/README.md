# TuahBots launch trailer

`out/tuahbots-trailer.mp4`: 31 s, 1920×1080, 30 fps, H.264 + AAC.

| Time | Scene |
|---|---|
| 0–3.7 s | "Hate making phone calls?" plus the on-hold timer |
| 3.7–7.5 s | "What if a bot made them for you?" and the TuahBots logo drop |
| 7.5–15 s | **1 · Ask**: Pat types the request in the `/app` chat, attaches the quote, and the call shows up under *Your calls* |
| 15–22.5 s | **2 · Tuah calls**: live call with Mike, AI disclosure, recording, transcript |
| 22.5–26 s | **3 · You get the answer**: notification, summary in chat, call marked *completed* |
| 26–28 s | Rapid fire: phone trees, voicemail, callbacks, hold music |
| 28–31 s | End card: "Let the bot make the call." |

## Rebuild

```bash
pip install numpy scipy
python3 soundtrack.py   # -> tuahbots-soundtrack.wav (original music + SFX, synthesized)
node render.mjs         # -> out/tuahbots-trailer.mp4 (needs Playwright + ffmpeg)
node render.mjs --stills 9,17,24   # PNG stills for quick checks
```

Open `trailer.html` in a browser for a live preview. Click to play it with the soundtrack.
